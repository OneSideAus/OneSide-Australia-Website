# Add a new sport

The full checklist lives in the assessment app repo, because most of the work
happens there:

1. Attach the `OneSideAus/oneside-australia` repository to this session if it
   isn't already (add_repo), and clone it.
2. Read `.claude/skills/add-sport/SKILL.md` in that repo and follow it exactly,
   for the sport given in the arguments. It covers both repos, including this
   website's steps (scripts.js, index.html marquee, faq.html, api/chat.js,
   updates.html).
